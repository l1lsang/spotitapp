# Pretendard

Pretendard v1.3.9, Regular / Medium / SemiBold / Bold static OTF faces.
Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/public/static
License: SIL Open Font License 1.1; complete notice in OFL.txt and the in-app license directory.

Loaded through Expo 57 useFonts so Expo Go and installed native apps share the same typography.
The original reference project uses the variable web font; static faces avoid platform-specific variable-font weight behavior.
